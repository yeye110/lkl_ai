# LKL\-AI — 简易 ReAct Agent 智能体框架

## 项目简介

本项目是一个**轻量、可扩展的 ReAct 智能体框架**，基于经典的 **Reason（推理）\+ Act（行动）** 模式实现。框架内置完整的 **推理思考、工具调用、结果反馈、迭代修正** 能力，结构清晰、低耦合，支持开发者自由自定义新增工具，快速搭建专属智能体业务流程。

项目使用示例可参考根目录 `glm-test.py`，包含完整的调用流程与使用示范。

## ✨ 核心能力

- **ReAct 推理机制**：大模型自主思考任务、拆解步骤、判断是否需要调用工具

- **通用工具调用能力**：支持函数工具调用、结果回传、多轮迭代执行

- **反馈闭环机制**：根据工具返回结果二次推理、修正答案、补全任务

- **高可扩展工具系统**：极简方式自定义新增工具，无需修改核心逻辑

- **轻量化架构**：代码简洁易懂，适合学习、二次开发与快速落地

## 🔧 自定义添加工具（核心扩展）

本框架支持**零侵入新增工具**，扩展步骤极其简单：

1. 在 `tools/` 目录下新建自定义工具脚本

2. 按照框架统一格式编写工具函数、工具描述、入参出参

3. 将工具注册到 Agent 调度池

4. Agent 会自动识别、自主判断是否调用该工具

所有工具调用、推理、反馈逻辑均由框架自动闭环，无需改动核心代码。
